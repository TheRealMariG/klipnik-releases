# Klipnik releases

Installers and update files for **Klipnik**, a Windows app that turns long videos into short
clips for TikTok, YouTube Shorts and Instagram Reels.

- **Download:** the latest installer is under [Releases](../../releases/latest).
- **Updates:** the app checks this repository for new versions. Every installer is signed with
  the app's update key, and the app refuses an update whose signature doesn't match.

This repository holds only the released installers. It contains no source code.
